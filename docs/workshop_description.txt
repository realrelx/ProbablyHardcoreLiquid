【English below】

== 一句话 ==
液体再也倒不干净，并给你一把能把它洗干净的喷壶。

== 这个 mod 做什么 ==
每个液体容器都有固有残留：残留 = min(容积 × 残留比例 × 粘度, 残留上限)。倾倒、转移、排空只带走「总量 − 残留」，两边组成保持同比例；瓶里只剩残渣时倒不出去，得兑入新液才能再倒。
37 种原版液体成分配有粘度表（水 = 1：酒精 1.2、食用油 80、淀粉糊 100、烧碱 13…），其他 mod 的液体默认按水处理。

== 实验室喷壶 ==
· 1000ml，1×2 格，约 80 信用点，只能倒掉或清洗别的容器，不能整壶转移。
· 拖到液体容器 = 连续稀释清洗：总喷量 M = 清洗倍率 × 目标残留（默认 3 倍），洗后残留比例 = e^(−M/c) ≈ 4.98%。
· 拖到水龙头装水（沿用当天水质与净化器判定），拖到排水口倒空。
· 贴图随液位切换（空 / 1/4 / 半 / 满），高清母版运行时按网格缩放。
· 化学家开局送一把满纯水（水质可配），博士与下层区化学商人有概率出售空壶。

Probably Hardcore Liquid — v0.9.15

== In one line ==
Liquids never pour out clean — and now you own a bottle that can actually clean them.

== What it does ==
Every liquid container keeps an inherent residue: residue = min(capacity x residue percent x viscosity, cap). Pouring, transferring or draining only moves (total - residue) and keeps the same composition on both sides; a container holding only residue cannot be poured again until fresh liquid is added.
A viscosity table covers all 37 vanilla liquid components (water = 1: alcohol 1.2, cooking oil 80, starch slurry 100, lye 13...); liquids from other mods default to water.

== Lab Spray Bottle ==
- 1000 ml, 1x2 grid, ~80 credits. It can only drain or rinse other containers; it cannot be poured out entirely.
- Drag onto a liquid container = continuous-dilution rinse: total spray M = rinse ratio x target residue (default 3x), final residue ratio = e^(-M/c) ~= 4.98%.
- Drag onto a faucet to refill (keeps that day's water quality and purifier checks), onto a drain to empty.
- Sprite follows the fill level (empty / quarter / half / full), scaled from a high-res master at runtime.
- The chemist starting kit includes a full spray of clean water (quality configurable); the doctor and the lower-levels chemist merchant may sell empty ones.

== This update (0.8.x -> 0.9.15) ==
- The spray bottle now occupies a true 1x2 grid and lands in the store warehouse instead of the counter or outside the shutter.
- New high-res sprites with area-averaged downsampling and invisible cell anchors.
- Fixed the 1 ml / 5 ml droppers being unable to draw while holding only residue; the residue system is fully preserved.
- Rinse model simplified back to p = e^(-M/c): viscosity only decides how much water you spend, not how clean it gets.
- Rinse guards: empty containers do nothing; rinsing is refused when the container holds more than (residue cap + configurable headroom).
- Config menu: rinse ratio is a numeric field (decimals allowed), volume headroom is numeric, doctor chance now rolls once per day.
- Everything is configurable. No capabilities declared; nightly machine flows are untouched.
