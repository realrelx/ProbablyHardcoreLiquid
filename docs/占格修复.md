# 占格修复 · 为什么是 7 格而不是 2×2，以及怎么放进仓库

## 一、症状

- 喷壶在库存里占的是「2×3+1」这种 7 格怪形状；
- 因此库存网格找不到连续空位 → 放不进仓库/背包；
- 开局赠壶又走了 `GraphUtils.EmporiumTryAdd`，物品停在柜台上；
- 柜台上的物品没有 `IS_OWNED_TAG`，于是拖不动、点不动——就是"没法与其他物品交互"。

## 二、根因（IL 实证）

`GameItem.SetSpriteAndShapeFromMod(modId, spriteKey)` 的形状算法：

```
rect = sprite.rect;                       // 像素
g    = UISettings.current.gridSize;       // int
cols = (int)rect.width  / g;              // 没有 Max(1, …)
rows = (int)rect.height / g;
for row in rows:
  for col in cols:
      x = rect.xMin + col*g + g/2;        // 每格「中心像素」
      y = rect.yMin + (rows-1-row)*g + g/2;
      shape[row][col] = texture.GetPixel(x,y).a > 0;
```

两个要害：

1. **格数 = floor(像素尺寸 / gridSize)**；74px 在 `gridSize ≈ 24` 时算出 **3×3**，
   而我们这张图瓶身只有 30px 宽，左右两列的中心像素是透明的 → 那两格被丢 → **9−2 = 7 格**。
2. **只用每格中心一个像素判定**，所以"看得见"不保证占格，图表再漂亮也可能整列不占。

旧版把 74px 当成"2×gridSize"是错的假设：`UISettings.Awake()` 里只有 `current = this`，
`gridSize` 是场景序列化值，离线拿不到常量，不能再猜。

## 三、修法

1. **运行时出图**：`EnsureSprites()` 读 `UISettings.current.gridSize`（public int 字段，直接读，
   不用反射 → 不给模组扫描器留 reflection 痕迹），把 74px 母图最近邻重采样成 **2g×2g** 画布。
   这样 `cols = rows = 2` 恒成立。
2. **占格锚点**：四个格中心坐标是 `(g/2, g/2)`、`(3g/2, g/2)`、`(g/2, 3g/2)`、`(3g/2, 3g/2)`。
   `ForceOpaque()` 在这些像素 alpha 为 0 时，从**所在格内**最近的可见像素借色并把 alpha 置 255；
   整格都空则填瓶身底色 `#DDE8EC`。肉眼看不出，但形状必定是满 2×2。
3. **画幅比例**：等比缩放 + 居中，保留原图细长瓶身，不为填满格子而拉伸。
4. **延迟重试**：`gridSize` 在标题画面可能还读不到，此时不缓存贴图，等进游戏后重算，
   否则会把兜底画布永久缓存下来、形状又变回 3×3。
5. **发放通道**：`GiftIfChemist` 改为先 `ModHelper.MoveItemToInventory(item)`（进背包），
   失败才退回 `GraphUtils.EmporiumTryAdd`，落地后补 `EnableTag("IS_OWNED_TAG", true)`。

## 四、日志与验收

| 日志 | 含义 |
|---|---|
| `spray sprites loaded: 4/4 (gridSize=24, canvas=48x48, anchorFixes=…)` | 画布按真实 gridSize 生成 |
| `spray gift placed, size=4` | 落地后占 4 格（2×2） |
| `gridSize unavailable yet; spray sprites deferred` | 太早调用，进游戏后会自动重算 |

游戏内验收：
1. 化学家开新档 → 背包装着喷壶（不是柜台），占 2×2 格；
2. 拖进仓库任意 2×2 空位 → 放得下；
3. 拖到液体容器 → 有交互（清洗），拖到排水口 → 倒掉。

## 五、遗留风险

- R1：玩家改分辨率/UI 缩放导致 `gridSize` 变化时，已生成的贴图不会自动重做（重启游戏即可）。
- R2：`ForceOpaque` 借的像素颜色来自同格，若整格透明则用底色——极细的瓶嘴可能被补出 1 个像素。
- R3：仓库放置还依赖 `GridShape.Intersects/FullyIntersects` 系列判定，若将来官方改成"整格覆盖率"而非"中心像素"，锚点法需重写。
