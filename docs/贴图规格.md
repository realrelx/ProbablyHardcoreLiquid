# 喷壶贴图规格（可直接发给 GPT / 画师）

目标：给《深空当铺：可能是偷的》做一个 2×2 格子的实验室喷壶，四张状态图。
游戏是**像素风/手绘风混合的等距 3/4 视角**，物品图标直接铺在透明底上，没有描边框、没有阴影底板。

## 1. 硬性参数

| 项 | 要求 |
|---|---|
| 画布 | **74 × 74 px**，透明背景（alpha=0） |
| 内容范围 | 不透明像素的 bbox 高度占画布 **85%–95%**（约 65–70 px）；宽度随原图长宽比，不强制（当前四联原图切出来是 30 px 宽） |
| 位置 | 水平居中（bbox 中心 x = 37±3），顶端距上边 2–6 px，底端距下边 2–6 px |
| 格式 | 单张 PNG，8-bit RGBA，无 ICC、无 EXIF |
| 文件 | `spray_empty.png` / `spray_quarter.png` / `spray_half.png` / `spray_full.png` |
| 边缘 | 硬边或 1px 抗锯齿均可，但 **不要外发光、不要投影**（投影会撑大 bbox，导致格数算错） |
| 尺寸原因 | 游戏的 `BuildShapeFromSprite` 用 `sprite.rect / UISettings.current.gridSize(≈36.57)` 整数截断得格数；74 px 落在 [2g, 3g) 区间 → 2×2 格。大于 109 px 会变 3×3，小于 73 px 会变 1×1。 |

## 2. 造型

- 一个**细长按压式喷壶**：瓶身竖直、圆肩、窄颈，顶部按压喷头 + 短喷嘴（喷嘴朝右上或正右，别超出 bbox）。
- 瓶身透明或半透明塑料（能看见里面液体），
  - 玻璃感高光：左侧 2–3 px 竖向高光条，右侧 1 px 反光边。
- 瓶身偏窄（当前切图实际约 30 px 宽、70 px 高），因为要放进 2×2 格却保持"手持小瓶"的观感；四张必须同宽同高、同一裁剪框，否则换液位时瓶身会跳。
- 已有素材：`_inbox_spray_source.png`（1254×1254 四联，左上空/右上 1/4/左下半个/右下满），用 `..\scripts\make_spray_textures.ps1 -Source <该图>` 一键重切。
- 底部不要加地面/阴影。

## 3. 四种状态（只有液体高度和颜色变化，外形完全一致）

| 文件 | 液面高度（占瓶身内腔） | 颜色 |
|---|---|---|
| `spray_empty.png` | 0%（空瓶，内壁可见） | 无液体；内壁淡青灰 `#C8D8DD` |
| `spray_quarter.png` | 25% | 清澈淡蓝 `#7FC7E8`，液面一条 1px 亮线 |
| `spray_half.png` | 55% | 同上，液面亮线 |
| `spray_full.png` | 85% | 同上，液面亮线，顶部留 2–3 px 空气 |

液体颜色统一用水的淡蓝（模组里喷壶默认装纯水），不要四种颜色，否则玩家会以为换了化学品。

## 4. 配色（对齐游戏 UI）

- 瓶身塑料/玻璃：`#DDE8EC` 主体、`#FFFFFF` 高光、`#9FB4BC` 暗部
- 喷头/按压件：`#6E7F88` 深灰、`#B9C6CC` 亮面
- 液体：`#7FC7E8` + 液面 `#CFF0FF`
- 标签环（可选，瓶身中部一圈）：`#E8D9A8` 米黄，**不要写字**

## 5. 一致性

- 四张图必须**同一底稿**，只改液面高度，保证切换时瓶身不跳。
- 视角与游戏其他物品一致：略微俯视、正面朝外，不要透视变形。
- 线条粗细 2 px 左右，与游戏内小物件（药瓶、注射器）同密度。

生成后自检：`.\test.ps1` 的第 2 节会检查尺寸、bbox 高度、水平居中和上下留边；不合格会直接 FAIL 并打印实际值。

## 7. 为什么是 74 而不是 72/76

游戏中 `gridSize` 运行时读取（`UISettings.current.gridSize`），本机反推 ≈ 36.57 px。
2 格的安全区间是 `[2g, 3g) ≈ [73.2, 109.7]`，74 是其中最小、最贴近 2 格的整数尺寸；
选 108 也可以（仍是 2×2，但四周会有大量透明边，物品看起来变小）。
