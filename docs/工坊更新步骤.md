# 工坊更新步骤（0.9.15）

> 上传是不可逆的公开操作，本工程只准备素材，不代传。执行前请确认三项：作品 ID、作者身份、变更说明。

## 0. 前置检查

- 游戏已完全退出（`deploy.ps1` 检测到进程会拒绝）。
- `D:\steam\steamapps\common\Probably Stolen\Mods\ProbablyHardcoreLiquid` 里 `manifest.xml` 是 `<ModVersion>0.9.15</ModVersion>`。
- 工坊条目沿用旧的 **publishedfileid 3830066983**（更新，不是新建）。

## 1. 上传目录

`upload\` 只放运行必需的两个文件：

| 文件 | 大小 |
| --- | --- |
| `ProbablyHardcoreLiquid.dll` | 817,152 B |
| `manifest.xml` | 1,268 B |

不要放：`src\`、`docs\`、`Textures\` 母版、`build\` 其它版本、`.ps1` 脚本——官方扫描会检查整个文件夹（脚本/可执行/美术源文件都会被拒）。

## 2. 上传（任选一种）

**A. steamcmd（推荐，命令行可复现）**

```
steamcmd +login <你的账号> +workshop_build_item "C:\Users\han\Documents\deepseek-harness\default-workspace\何小鲁框架正式版本\projects\ProbablyHardcoreLiquid\workshop.vdf" +quit
```

`workshop.vdf` 已填好 `appid 4348910`、`publishedfileid 3830066983`、`contentfolder`、`previewfile`、`visibility 0`、`title`、内联 `changenote`。
`changenote` 是内联文本；要改更新说明就改这一行（VDF 里不能用文件路径代替）。

**B. Steamworks SDK 上传器**
`SteamWorkshopUploader.exe` + 同目录 `workshop_item.vdf`，字段含义与上面一致。

## 3. 工坊页文案（手动粘贴）

- **简介（description）**：整段复制 `docs\workshop_description.txt`。它分中英两部分，中文在前；工坊页支持换行，直接粘即可。
- **更新说明（change notes）**：复制 `docs\workshop_changenote.txt` 第一段（中文）；需要英文再追加第二段。
- **封面**：`workshop_preview.png`（沿用旧封面，506 KB，未超 1 MB）。

## 4. 发布后校验

1. 打开创意工坊条目，确认版本/更新说明是 0.9.15，订阅数与文件大小合理。
2. 用另一个不带本地版的账号（或临时改名 `Mods\ProbablyHardcoreLiquid`）订阅，确认工坊版能加载：日志出现 `[ModLoader] audit: ProbablyHardcoreLiquid v0.9.15 ... source=Workshop`。
3. 恢复本地开发版时注意：**同名 ID 时本地版优先**（日志会打 `the local copy wins over the Workshop copy`），这是预期行为，不是冲突。

## 5. 版本号约定

`manifest.xml` 的 `ModVersion` 是唯一版本来源：`build.ps1` 用它命名 `build\<版本>\`，`test.ps1 -Version` 校验它，工坊 `changenote` 与简介里的版本号必须与它一致。下次改动先改 manifest 再构建。
